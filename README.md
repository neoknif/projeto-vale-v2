Plataforma institucional e comunitária do **Projeto Vale**, focada em inclusão social, transparência e suporte direto a famílias no Vale do Paraíba. O projeto passou por uma refatoração completa para garantir alta performance, experiência de usuário aprimorada (UX) e código modularizado.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as melhores práticas modernas de desenvolvimento web:

* **React** (v18+) com **TypeScript**
* **Vite** (Build tool ultrarrápida)
* **Vimeo Player API** (Integração de vídeos em alta performance)
* **CSS Moderno** (Variáveis customizadas, Flexbox e animações *Skeleton Loading*)
* **Vercel** (Hospedagem e Deploy Contínuo)

---

## ✨ Principais Melhorias e Recursos

* **Componentização Avançada:** Isolamento do player de vídeo e seções para manutenibilidade limpa do código.
* **Performance Otimizada:** Implementação de `loading="lazy"` em iframes e animações de carregamento (*Skeleton Shimmer*) para reduzir o tempo de percepção de espera.
* **SEO & Social Sharing:** Configuração completa de Meta Tags e Open Graph para prévias otimizadas ao compartilhar o link no WhatsApp e redes sociais.
* **Responsividade Completa:** Layout adaptável para dispositivos móveis, tablets e desktops.

---

## 🛠️ Como Executar o Projeto Localmente

Certifique-se de ter o **Node.js** instalado em sua máquina. Siga os passos abaixo:

```bash
# 1. Clone o repositório
git clone [https://github.com/neoknif/projeto-vale-v2.git](https://github.com/neoknif/projeto-vale-v2.git)

# 2. Acesse a pasta do projeto
cd projeto-vale-v2

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento local
npm run dev
